# Project overview

This repository contains a dependency-free, multi-page static website for the Wuhan Sports University Intangible Cultural Heritage Research Center.

## Run on Replit

The website source is in `whyj-redesign/`.

Start it with:

```sh
cd whyj-redesign && python3 -m http.server 5000 --bind 0.0.0.0
```

The Replit web workflow runs this command and serves the site on port 5000. No package installation, build step, environment variables, or external services are required.
